# One-page sites

One HTML file, styles inline in a `<style>` block, no JavaScript unless the brief asks for it.

## Rules

- Start with `<!doctype html>`, set `lang` on `<html>`, and give the page a `<title>` and a viewport meta tag.
- Put the content in `<main>` with one `<h1>` and `<h2>` sections under it.
- Give every image an `alt` attribute that says what it shows.
- Use one primary call to action and put it above the fold.
- Save the page as `outputs/index.html`.
