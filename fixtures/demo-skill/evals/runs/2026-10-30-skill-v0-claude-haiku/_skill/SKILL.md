# Release notes

Write the note for the person who uses the software, not the person who built it.

## Rules

- Start with a one-line title that names the change in plain words.
- Say what changed and what it means for the reader, in that order.
- Keep the note under 120 words.
- Never use the words "excited", "thrilled" or "revolutionary".
- End with one line that says where to find the change.
